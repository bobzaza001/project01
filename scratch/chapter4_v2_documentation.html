บทที่ 4

ผลการดำเนินงาน

โครงงานระบบการยืมอุปกรณ์ห้องคอมพิวเตอร์ มีผลการดำเนินงาน ดังนี้

4.1 ผลการออกแบบ

ผู้จัดทำโครงงานได้ดำเนินการออกแบบและพัฒนาส่วนติดต่อผู้ใช้งาน (User Interface: Front-End) ของระบบการยืมอุปกรณ์ห้องคอมพิวเตอร์ โดยแบ่งหน้าจอการทำงานออกเป็นส่วนต่างๆ เพื่อรองรับการใช้งานของนักเรียน นักศึกษา อาจารย์ และผู้ดูแลระบบได้อย่างครบถ้วน ดังนี้

4.1.1 หน้าเข้าสู่ระบบ (Login Page)

หน้าเข้าสู่ระบบถูกออกแบบให้ผู้ใช้งานสามารถเข้าสู่ระบบด้วยชื่อผู้ใช้ (Username) หรืออีเมลสถาบัน พร้อมรหัสผ่าน นอกจากนี้ยังมีแท็บสแกน QR Code เพื่อเข้าสู่ระบบผ่านสมาร์ตโฟน และส่วนจำลองบัญชีทดสอบระบบสำหรับผู้ดูแลระบบและผู้ใช้ทั่วไป

ภาพที่ 4-1 แสดงหน้าต่างเข้าสู่ระบบ (Login Page)

4.1.2 หน้าสมัครสมาชิก (Register Page)

หน้าต่างสำหรับลงทะเบียนผู้ใช้งานใหม่ โดยผู้ใช้จะต้องระบุชื่อผู้ใช้งาน, ชื่อ-นามสกุลจริง, อีเมลสถาบัน (@atcc.ac.th), และรหัสผ่านความปลอดภัย เพื่อสร้างบัญชีเข้าใช้งานระบบยืม-คืนอุปกรณ์

[รูปหน้าต่างสมัครสมาชิก (Register Page)] (แสดงฟอร์มกรอกชื่อผู้ใช้, ชื่อ-นามสกุล, อีเมลสถาบัน และรหัสผ่าน)
ภาพที่ 4-2 แสดงหน้าต่างสมัครสมาชิกผู้ใช้งานใหม่ (Register Page)

4.1.3 หน้าลืมรหัสผ่าน (Forgot Password Page)

หน้าต่างสำหรับขอรีเซ็ตรหัสผ่านในกรณีที่ผู้ใช้งานลืมรหัสผ่าน โดยระบบจะให้ระบุอีเมลสถาบันที่ลงทะเบียนไว้เพื่อตรวจสอบและดำเนินการส่งลิงก์ตั้งรหัสผ่านใหม่

[รูปหน้าต่างลืมรหัสผ่าน (Forgot Password Page)] (แสดงฟอร์มระบุอีเมลเพื่อขอรีเซ็ตรหัสผ่านเข้าสู่ระบบ)
ภาพที่ 4-3 แสดงหน้าต่างขอรีเซ็ตรหัสผ่าน (Forgot Password Page)

4.1.4 หน้าจอหลักสำหรับผู้ใช้ทั่วไป / คลังอุปกรณ์ (User Dashboard & Catalog)

หน้าจอหลักสำหรับนักเรียน นักศึกษา และอาจารย์ ประกอบด้วยแถบค้นหาอัจฉริยะ ตัวกรองตามประเภท (ครุภัณฑ์/วัสดุสิ้นเปลือง), ตัวกรองตามอาคาร ชั้น และห้องปฏิบัติการ พร้อมแสดงการ์ดรายการครุภัณฑ์ รูปภาพ สถานะสต็อกคงเหลือ และปุ่มสำหรับกดยื่นขอยืมหรือขอเบิก

ภาพที่ 4-4 แสดงหน้าจอหลักคลังอุปกรณ์และแดชบอร์ดผู้ใช้ (User Dashboard & Catalog)

ภาพที่ 4-5 แสดงหน้าต่างฟอร์มยื่นคำขอยืมครุภัณฑ์ (Borrow Request Modal)

4.1.6 หน้าต่างฟอร์มยื่นคำขอเบิกวัสดุสิ้นเปลือง (Consumable Request Modal)

หน้าต่างสำหรับยื่นคำขอเบิกวัสดุสิ้นเปลือง (Consumable) เช่น กระดาษพิมพ์, หมึกพิมพ์ โดยผู้ใช้ระบุจำนวนที่ต้องการเบิกใช้งาน ซึ่งระบบจะส่งเรื่องให้แอดมินอนุมัติตัดสต็อกโดยไม่ต้องนำกลับมาส่งคืน

[รูปหน้าต่างฟอร์มยื่นคำขอเบิกวัสดุสิ้นเปลือง (Consumable Request Modal)] (แสดงฟอร์มระบุจำนวนชิ้นของวัสดุที่ต้องการขอเบิกใช้งาน)
ภาพที่ 4-6 แสดงหน้าต่างฟอร์มยื่นคำขอเบิกวัสดุสิ้นเปลือง (Consumable Request Modal)

4.1.7 หน้าต่างฟอร์มแจ้งส่งคืนครุภัณฑ์พร้อมแนบรูปถ่ายหลักฐาน (Return Equipment Modal)

หน้าต่างสำหรับแจ้งส่งคืนครุภัณฑ์ โดยระบบบังคับให้ผู้ยืมต้องอัปโหลดรูปถ่ายสภาพอุปกรณ์ขณะส่งคืน เพื่อใช้เป็นหลักฐานให้ผู้ดูแลระบบตรวจสอบสภาพของก่อนกดยืนยันรับคืนเข้าคลัง

[รูปหน้าต่างแจ้งส่งคืนครุภัณฑ์ (Return Equipment Modal)] (แสดงช่องอัปโหลดรูปถ่ายสภาพอุปกรณ์ขณะส่งคืน และปุ่มยืนยันส่งคืน)
ภาพที่ 4-7 แสดงหน้าต่างแจ้งส่งคืนครุภัณฑ์พร้อมแนบรูปถ่ายหลักฐาน (Return Equipment Modal)

4.1.8 หน้าแจ้งซ่อมครุภัณฑ์ชำรุด (Repair Request Page)

หน้าต่างสำหรับนักเรียน นักศึกษา และอาจารย์ ในการยื่นเรื่องแจ้งซ่อมครุภัณฑ์ที่พบว่าชำรุดเสียหาย โดยสามารถเลือกชื่ออุปกรณ์และกรอกรายละเอียดอาการชำรุดเบื้องต้นเพื่อให้เจ้าหน้าที่ตรวจสอบและดำเนินการซ่อมบำรุง

[รูปหน้าต่างแจ้งซ่อมครุภัณฑ์ชำรุด (Repair Request Page)] (แสดงฟอร์มเลือกอุปกรณ์ชำรุด และช่องกรอกรายละเอียดอาการเสียหาย)

หน้าแสดงข้อมูลส่วนตัวของผู้ใช้งาน สถิติจำนวนครั้งที่ยืม ฟอร์มแก้ไขชื่อ-นามสกุล อีเมล เปลี่ยนรหัสผ่าน และฟังก์ชันอัปโหลดรูปภาพโปรไฟล์ประจำตัว

ภาพที่ 4-9 แสดงหน้าต่างข้อมูลส่วนตัวและแก้ไขโปรไฟล์ (User Profile Page)

4.2 ผลการประเมินความพึงพอใจต่อโครงงานคอมพิวเตอร์

โครงงานระบบการยืมอุปกรณ์ห้องคอมพิวเตอร์ ผู้จัดทำโครงงานได้ออกแบบการประเมินความพึงพอใจกับการใช้งานของกลุ่มเป้าหมาย (นักเรียน/นักศึกษาสาขาวิชาคอมพิวเตอร์ จำนวน 50 คน) โดยมีครูที่ปรึกษาโครงงานเป็นผู้ตรวจสอบหาประสิทธิภาพของแบบประเมิน ทำให้ครบตามสถิติที่เราใช้ประเมิน ซึ่งได้ผลการวิเคราะห์ข้อมูลความพึงพอใจดังแสดงในตารางที่ 4-1

ตาราง 4-1 แสดงผลค่าเฉลี่ยเลขคณิตการประเมินความพึงพอใจของโครงงานระบบการยืมอุปกรณ์ห้องคอมพิวเตอร์ (จำนวน 50 คน)
รายการการประเมิน ค่าเฉลี่ย (x̄) S.D. ความพึงพอใจ
1. ด้านความตรงตามความต้องการของระบบ (Functional Requirements)
1.1 ความสะดวกในการค้นหาและคัดกรองข้อมูลครุภัณฑ์ตามอาคารและห้องจัดเก็บ 4.52 0.61 มากที่สุด
1.2 ความสะดวกรวดเร็วในการยื่นคำขอยืมครุภัณฑ์และการขอเบิกวัสดุสิ้นเปลือง 4.56 0.54 มากที่สุด
1.3 ความสะดวกในการแนบรูปถ่ายหลักฐานสภาพอุปกรณ์ขณะส่งคืน 4.52 0.58 มากที่สุด
