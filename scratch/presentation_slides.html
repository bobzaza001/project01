นำเสนอโครงงานระดับประกาศนียบัตรวิชาชีพ (ปวช.) สาขาวิชาคอมพิวเตอร์

ระบบการยืมอุปกรณ์ห้องคอมพิวเตอร์

Computer Lab Equipment & Material Borrow-Return Management System

วิทยาลัยเทคโนโลยีพณิชยการอยุธยา (ATCC)
ระบบเว็บแอปพลิเคชันจัดการยืม-คืนครุภัณฑ์และวัสดุอุปกรณ์แบบเรียลไทม์

ที่มาและความสำคัญของปัญหา

Problem Statement
ระบบเดิมเป็นสมุดจด
การบันทึกการยืม-คืนด้วยสมุดกระดาษ ทำให้เกิดความล่าช้า ข้อมูลตกหล่น สูญหายได้ง่าย และไม่สามารถตรวจสอบสต็อกคงเหลือได้แบบทันที
ขาดระบบติดตามสถานะ
นักเรียนและอาจารย์ไม่ทราบว่าอุปกรณ์ชิ้นใดว่างให้ยืมจริง ต้องเดินมาสอบถามที่ห้องปฏิบัติการ และเกิดปัญหาการส่งคืนเกินกำหนดบ่อยครั้ง
ไม่มีหลักฐานสภาพของ
เมื่ออุปกรณ์ชำรุดเสียหาย ไม่สามารถระบุได้ชัดเจนว่าเกิดในระหว่างการใช้งานของผู้ใด เนื่องจากไม่มีระบบแนบรูปถ่ายหลักฐานขณะส่งคืน

วัตถุประสงค์ของโครงงาน

Project Objectives
1. เพื่อพัฒนาเว็บแอปพลิเคชัน
พัฒนา ระบบการยืมอุปกรณ์ห้องคอมพิวเตอร์ เพื่ออำนวยความสะดวกในการยืม-คืนครุภัณฑ์ และการขอเบิกวัสดุสิ้นเปลืองผ่านเครือข่ายออนไลน์แบบ 24 ชั่วโมง
2. เพื่อเพิ่มประสิทธิภาพและลดความผิดพลาด
มีระบบตัดสต็อกอัตโนมัติ การตรวจสอบสิทธิ์ตามบทบาท (Admin, Teacher, Student) และการแจ้งเตือนสถานะคำขอผ่านทางอีเมล
3. เพื่อสร้างความโปร่งใสในการส่งคืน
มีระบบบังคับแนบรูปถ่ายหลักฐานสภาพอุปกรณ์ขณะส่งคืน เพื่อให้ผู้ดูแลระบบตรวจสอบสภาพของก่อนกดยืนยันรับคืนเข้าคลัง
4. เพื่อประเมินความพึงพอใจ
เพื่อประเมินความพึงพอใจในการใช้งานระบบของกลุ่มตัวอย่างนักเรียน/นักศึกษาสาขาวิชาคอมพิวเตอร์ จำนวน 50 คน

ภาษาและเทคโนโลยีที่ใช้ในการพัฒนา

Tech Stack & Architecture
ฝั่ง Back-End & Logic
  • Python 3.11 — ภาษาหลักในการประมวลผลระบบ
  • Flask Framework — สถาปัตยกรรม Modular Blueprints
  • Flask-Login — ระบบ Session & Role-Based Auth
  • Flask-Mail (SMTP) — ระบบส่งอีเมลแจ้งเตือนอัตโนมัติ
  • OpenPyXL / ReportLab — ส่งออกรายงาน Excel & PDF
ฝั่ง Front-End & ฐานข้อมูล
  • HTML5 & Jinja2 — โครงสร้างเว็บและเทมเพลตฝั่งเซิร์ฟเวอร์
  • Modern CSS3 — Glassmorphism Theme (Dark/Light)
  • Vanilla JavaScript — Debounce Search, Modal, PWA
  • PostgreSQL / SQLite — ฐานข้อมูลเชิงสัมพันธ์ Relational DB
  • Vercel & Neon Cloud — Cloud Serverless Hosting

โครงสร้างฐานข้อมูล (Database Schema)

PostgreSQL / SQLAlchemy ORM
ตารางผู้ใช้งาน & สถานที่
• users: เก็บ id, student_id (11 หลัก), username, password_hash, full_name, email, role
• buildings: อาคารเรียน (id, name)
• floors / rooms: ชั้นเรียน และห้องปฏิบัติการ
ตารางครุภัณฑ์ & วัสดุ
• equipments: id, equipment_code, name, category, item_type (durable/consumable), quantity, available_quantity, status, image_url, room_id
ตารางคำขอ & การซ่อม
• borrow_requests: คำขอยืม-คืน, วันเวลารับของ, กำหนดส่งคืน, return_image (Base64), สถานะ
• repair_requests: คำขอแจ้งซ่อมอุปกรณ์ชำรุด

ระบบเข้าสู่ระบบและการกู้คืนบัญชี

Authentication & Recovery
1. สมัครด้วยรหัสนักศึกษา
• นักศึกษากรอก รหัสนักศึกษา 11 หลัก และอีเมลสถาบัน (@atcc.ac.th)
• ระบบนำรหัสนักศึกษาไปเป็น Username สำหรับเข้าสู่ระบบทันที
• อาจารย์สมัครด้วยชื่อ-นามสกุลจริง
2. ล็อกอินอัจฉริยะ
• เข้าสู่ระบบได้ด้วย รหัสนักศึกษา, ชื่อ-นามสกุลจริง, หรืออีเมลสถาบัน
• รองรับการสแกน QR Code เข้าสู่ระบบ ผ่านสมาร์ตโฟน
• มีระบบจำลองบัญชีเพื่อทดสอบระบบได้ทันที
3. ศูนย์กู้คืนบัญชี (OTP)
• ค้นหาชื่อผู้ใช้ (Find User): กรอกอีเมลเพื่อดู Username/รหัสนักศึกษา
• รีเซ็ตรหัสผ่านใหม่ (OTP): ยืนยันรหัส OTP 6 หลักแล้วตั้งรหัสผ่านใหม่ได้ทันที

คลังอุปกรณ์และการค้นหาอัจฉริยะ

Equipment Catalog & Filtering
ระบบตัวกรอง 4 มิติ
• ประเภทอุปกรณ์: ครุภัณฑ์ (ยืม-คืน) หรือ วัสดุสิ้นเปลือง (ขอเบิก)
• สถานที่จัดเก็บ: กรองแยกตาม อาคารเรียน, ชั้น, และห้องปฏิบัติการ
• หมวดหมู่: ไอทีและคอมพิวเตอร์, เฟอร์นิเจอร์, เครื่องใช้ไฟฟ้า, โสตทัศนูปกรณ์
• สิทธิ์การยืม: พกพา/ยืมกลับได้ หรือ ประจำห้อง
ค้นหาแบบเรียลไทม์ (Debounce)
• ค้นหาด้วยชื่ออุปกรณ์, รหัสครุภัณฑ์ หรือยี่ห้อ ได้ทันทีขณะพิมพ์
• ใช้เทคโนโลยี JavaScript Debouncing ทำให้การแสดงผลลื่นไหล ไม่หน่วงหน้าจอ
• แสดงป้ายสถานะสต็อกคงเหลือชัดเจน (พร้อมให้ยืม / ถูกยืมหมด / อยู่ระหว่างซ่อม)

ขั้นตอนการยืม-คืน และการเบิกวัสดุ

Borrow-Return Workflow
1. ยื่นคำขอ
เลือกวันเวลารับของ และระบุจำนวนวันยืม 1-30 วัน
2. แอดมินอนุมัติ
ตัดสต็อกคงเหลืออัตโนมัติ และส่งอีเมลแจ้งผู้ยืม
3. ส่งคืนแนบรูป
ผู้ยืมกดส่งคืนพร้อมอัปโหลดรูปถ่ายสภาพอุปกรณ์
4. ยืนยันรับคืน
แอดมินตรวจรูปภาพแล้วกดยืนยัน คืนสต็อกเข้าคลัง

แดชบอร์ดและการจัดการของผู้ดูแลระบบ

Admin Management Hub
แดชบอร์ดสรุปสถิติ & อนุมัติ
• สรุปยอดครุภัณฑ์ทั้งหมด, ยอดที่กำลังถูกยืม, ยอดรออนุมัติ, ยอดชำรุด
• ตารางจัดการคำขอยืม (ปุ่มอนุมัติ / ปฏิเสธพร้อมระบุเหตุผล)
• ตารางตรวจสอบหลักฐานรูปภาพการส่งคืน (ปุ่มรับของคืนเข้าคลัง)
• ตารางติดตามและอัปเดตสถานะการแจ้งซ่อมครุภัณฑ์
จัดการครุภัณฑ์และสถานที่ (CRUD)
• เพิ่ม/แก้ไข/ลบ ครุภัณฑ์และวัสดุสิ้นเปลือง พร้อมอัปโหลดรูปภาพ
• จัดการผังสถานที่: เพิ่ม/แก้ไข อาคารเรียน, ชั้นเรียน, และห้องปฏิบัติการ
• Audit Logs: ตรวจสอบประวัติการแก้ไขข้อมูลของแอดมินย้อนหลังได้ทุกกิจกรรม

ระบบรายงานทางการ และฟังก์ชันเสริม

Reports & Mobile Features
รายงาน Excel (.xlsx)
ส่งออกรายงานประวัติการยืม-คืน, สถิติสต็อกคงคลัง, และประวัติ Audit Logs เป็นไฟล์ Excel จัดสไตล์หัวตารางอย่างเป็นทางการ
พิมพ์รายงาน PDF (A4)
หน้ารายงานสรุปประวัติทางการ จัดหน้าขนาดกระดาษ A4 พร้อมหัวเอกสารราชการและช่องลงนามผู้มีอำนาจ สั่งพิมพ์ได้ทันที
ป้ายโปสเตอร์ QR Code
พิมพ์ป้ายโปสเตอร์ประชาสัมพันธ์ขนาด A4 แปะหน้าห้องปฏิบัติการ เพื่อให้นักศึกษาสแกนเข้าสู่ระบบผ่านสมาร์ตโฟนได้สะดวกรวดเร็ว

ผลการทดสอบระบบ (System Testing)

Black-Box Testing (20 Test Cases)
กลุ่มการทดสอบ ประเด็นการทดสอบหลัก จำนวนเคส ผลการทดสอบ
1. การเข้าสู่ระบบ & สิทธิ์ ล็อกอิน Admin, Teacher, Student, รหัสผิด, ป้องกันเข้าข้ามสิทธิ์ 5 Cases ผ่าน 100%
2. ฟังก์ชันผู้ใช้ (Student/Teacher) ค้นหาอุปกรณ์, ขอยืมครุภัณฑ์, เบิกวัสดุ, บล็อกของหมด, คืนแนบรูป, แจ้งซ่อม 10 Cases ผ่าน 100%
3. การจัดการของผู้ดูแลระบบ อนุมัติคำขอ, ปฏิเสธระบุเหตุผล, รับคืนเข้าคลัง, จัดการสถานที่, ออกรายงาน 5 Cases ผ่าน 100%
รวมการทดสอบทั้งหมด 20 Cases ผ่านครบทุกเคส
