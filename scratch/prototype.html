แบบร่างหน้าจอส่วนต่อประสานผู้ใช้แบบมินิมอล (Minimalist UI Wireframes)

ระบบจัดการยืม-คืนครุภัณฑ์ห้องปฏิบัติการคอมพิวเตอร์ (LAB Equipment Management System)

1. แบบร่างกลุ่มหน้าจอฝั่งผู้ใช้งานทั่วไป และอาจารย์ (User Flow Wireframes)

จัดแสดงแบบร่างโครงสร้างหน้ารายการคลังครุภัณฑ์หลัก (User Dashboard / Catalog), กล่องข้อความยืนยันการกดยืมส่งคืน (Borrow/Return Modal), และหน้าประวัติข้อมูลส่วนตัวผู้ใช้ (My Profile Page)

รูปที่ 1: แบบร่างหน้าจอฝั่งผู้ใช้ทั่วไปและอาจารย์ (User Catalog, Borrow Modal, and Profile)

คำอธิบายรายฟังก์ชันและระบบย่อย:

หน้าจอ / ฟังก์ชัน ผู้ใช้งาน คำอธิบายการทำงานแบบร่าง
หน้าคลังอุปกรณ์ (User Dashboard | Catalog) User Teacher ช่องค้นหาด้านบนสำหรับพิมพ์กรองอุปกรณ์ และแสดงการ์ดรายการครุภัณฑ์พร้อมปุ่ม "BORROW" เพื่อขอยืม หรือปุ่ม "DETAILS" ดูพิกัดจัดเก็บ
กล่องป๊อปอัปขอยืม-คืน (Borrow/Return Pop-up Modal) User Teacher หน้าต่างขนาดเล็กที่จะแสดงเมื่อกดทำรายการ เพื่อระบุวันเดินทางมารับของ (Date From) กำหนดวันที่จะนำมาส่งคืน (Date To) หรือใช้ถ่ายรูปอัปโหลดแนบส่งคืน
หน้าข้อมูลส่วนตัว (My Profile Page) User Teacher แสดงภาพโปรไฟล์ ประวัติของสมาชิก รายการครุภัณฑ์ที่กำลังกดยืมใช้งานอยู่ในขณะนี้ และตารางตรวจสอบวันครบกำหนดส่งคืน (Due Date)

2. แบบร่างกลุ่มหน้าจอการจัดการของแอดมิน (Admin Management Wireframes)

จัดแสดงหน้าจอแอปพลิเคชันฝั่งผู้ดูแลระบบ ประกอบด้วย หน้ารายการอาคารและชั้นเรียนห้องปฏิบัติการ (Buildings & Floors List), หน้าจอเพิ่มสถานที่ (Add Building Form) และแบบฟอร์มการอัปเดตรายละเอียดครุภัณฑ์ (Edit Equipment Details Form)

รูปที่ 2: แบบร่างหน้าจอบริหารข้อมูลสถานที่และอุปกรณ์ของแอดมิน (Admin Catalog & Setup Forms)

คำอธิบายรายฟังก์ชันและระบบย่อย:

หน้าจอ / ฟังก์ชัน ผู้ใช้งาน คำอธิบายการทำงานแบบร่าง
หน้าอาคารและชั้น (Buildings & Floors) Admin แสดงผลแบบ Tree-hierarchy แยกตามตึก ชั้น และแสดงชื่อห้องเรียนปฏิบัติการคอมพิวเตอร์ที่อยู่ในสังกัดชั้นนั้นๆ
หน้าเพิ่มอาคาร (Add Building Page) Admin แบบฟอร์มการบันทึกตึกใหม่ในระบบ ประกอบด้วยช่องกรอกชื่อตึก (Building Name), ที่อยู่ตึก (Address) และเลือกจำนวนชั้น (Floors)
หน้าเพิ่มอุปกรณ์ ลบอุปกรณ์ และแก้ไขอุปกรณ์ (Add/Edit/Delete Equipment) Admin แบบฟอร์มปรับแต่งข้อมูลสต็อกคลังครุภัณฑ์ สำหรับกรอกรหัสครุภัณฑ์ (Equipment ID), ชื่ออุปกรณ์ (Name), หมวดหมู่ (Type), สถานที่จัดเก็บ (Location) และกดยืนยันปุ่ม UPDATE เพื่อเซฟบันทึก

3. แบบร่างหน้าจอบริการอื่นๆ (Auxiliary Screens Wireframes)

จัดแสดงแบบร่างหน้าจอเพิ่มเติม ได้แก่ หน้าต่างแจ้งเตือนระบบ (System Notifications), หน้ารายการติดต่อเร่งด่วน (Contact Page) และหน้าแจ้งซ่อมครุภัณฑ์ชำรุด (Repair Request Form)

รูปที่ 3: แบบร่างหน้าจอแจ้งเตือน การติดต่อ และหน้าแจ้งซ่อมครุภัณฑ์ชำรุด

คำอธิบายรายฟังก์ชันและระบบย่อย:

หน้าจอ / ฟังก์ชัน ผู้ใช้งาน คำอธิบายการทำงานแบบร่าง
หน้าจอการแจ้งเตือน (Notifications Page) User Teacher Admin หน้ารวมประวัติการแจ้งข่าวสารในระบบ เช่น การอนุมัติใบยืม, แจ้งเตือนแอดมินตรวจสอบการซ่อม, หรือการแจ้งทวงส่งคืนล่าช้า
หน้าจอตารางการติดต่อ (Contact Page) User Teacher หน้าแสดงประวัติและรายชื่อบุคคลผู้ติดต่อ ข้อมูลช่องทางการสื่อสาร อีเมล และเบอร์โทรศัพท์ติดต่อกับเจ้าหน้าที่พนักงานคลังคอยดูแลระบบ
หน้าจอส่งรายงานการแจ้งซ่อม (Repair Request Page) User Teacher แบบฟอร์มการแจ้งซ่อมครุภัณฑ์ชำรุดเสียหาย โดยกรอกชื่อผู้แจ้ง รหัสอุปกรณ์ อาการชำรุด (Issue Description) เลือกระดับความเร่งด่วน และสามารถอัปโหลดภาพถ่ายประกอบได้
