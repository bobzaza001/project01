แบบร่างหน้าจอส่วนต่อประสานผู้ใช้ (User Interface Prototypes)

ระบบจัดการยืม-คืนครุภัณฑ์ห้องปฏิบัติการคอมพิวเตอร์ (LAB Equipment Management System)

1. แบบร่างหน้าจอเข้าสู่ระบบ (Login Page) - สำหรับผู้ใช้งานทุกคน

หน้าจอเข้าสู่ระบบถูกออกแบบให้อยู่ในรูปแบบ Glassmorphism ธีมมืด (Dark Theme) เพื่อความสวยงามและสบายตาในการใช้งานตอนค่ำคืน รองรับทั้งสิทธิ์ผู้ใช้ทั่วไป อาจารย์ และแอดมิน

รูปที่ 1: แบบร่างหน้าจอเข้าสู่ระบบ (Login Page)

รายละเอียดฟังก์ชันการทำงาน:

ฟังก์ชัน (Features) ผู้เกี่ยวข้อง (Actors) รายละเอียดการทำงาน
ระบบตรวจสอบสิทธิ์ตรง (Credential Login) User Teacher Admin กรอก Username (ชื่อผู้ใช้) และ Password (รหัสผ่าน) เพื่อเข้าสู่ระบบผ่านการตรวจสอบสิทธิ์บนเซิร์ฟเวอร์โดยตรง
การลงชื่อเข้าใช้ผ่าน Google (Google OAuth) User Teacher ปุ่มล็อกอินด้วยบัญชีอีเมล Google ของสถาบัน (@atcc.ac.th) เพื่อความสะดวกรวดเร็วโดยไม่ต้องจำรหัสผ่าน

2. แบบร่างหน้าจอหลักและคลังอุปกรณ์ (User Dashboard & Catalog) - สำหรับผู้ใช้งานทั่วไป และอาจารย์

หน้ารายการคลังอุปกรณ์หลักหลังผู้ใช้ล็อกอินสำเร็จ แสดงผลการ์ดข้อมูลครุภัณฑ์และวัสดุอย่างครบถ้วน พร้อมระบบดึงตัวกรอง (Filter) ค้นหาอย่างรวดเร็ว

รูปที่ 2: แบบร่างหน้าจอหลักผู้ใช้ทั่วไปและอาจารย์ (User Dashboard)

รายละเอียดฟังก์ชันการทำงาน:

ฟังก์ชัน (Features) ผู้เกี่ยวข้อง (Actors) รายละเอียดการทำงาน
การค้นหาและกรองข้อมูลแบบเรียลไทม์ (Search & Filters) User Teacher พิมพ์ค้นหาชื่อรหัสครุภัณฑ์ (มี Debounce 150ms ป้องกันแป้นพิมพ์หน่วง) และกรองเลือกตามหมวดหมู่ อาคาร ชั้น หรือห้องเรียนปฏิบัติการได้
ยื่นคำขอยืมครุภัณฑ์ (Durable Checkout) User Teacher กดปุ่ม "BORROW" เพื่อระบุวันเวลาที่จะเข้ามารับอุปกรณ์ครุภัณฑ์ และจำนวนวันที่จะขอยืม (จำกัด 1-30 วัน) เพื่อส่งเรื่องให้แอดมินอนุมัติ
ยื่นคำขอเบิกวัสดุสิ้นเปลือง (Consumable Checkout) User Teacher กดปุ่ม "CHECKOUT" เพื่อระบุจำนวนชิ้นวัสดุที่จะขอเบิกไปใช้งานทันที (หักยอดคงเหลือเมื่อได้รับการอนุมัติ และไม่ต้องส่งคืน)
การส่งคืนครุภัณฑ์และแนบรูปภาพ (Return & Upload Image) User Teacher เมื่อใช้งานเสร็จ ผู้ใช้ต้องกดคืนในระบบและถ่ายรูปสภาพครุภัณฑ์ ณ เวลาที่ส่งคืนอัปโหลดแนบเป็นหลักฐานการส่งคืน เพื่อให้แอดมินกดยืนยันรับของเข้าคลัง

3. แบบร่างหน้าจอควบคุมของผู้ดูแลระบบ (Admin Dashboard Panel) - สำหรับผู้ดูแลระบบ

หน้าหลักของแอดมินสำหรับตรวจดูรายงานวิเคราะห์สต็อก สถิติประเภทครุภัณฑ์ และจัดการคำขอยืม-คืนที่ค้างการทำรายการในระบบ

รูปที่ 3: แบบร่างหน้าจอแดชบอร์ดจัดการของแอดมิน (Admin Dashboard)

รายละเอียดฟังก์ชันการทำงาน:

ฟังก์ชัน (Features) ผู้เกี่ยวข้อง (Actors) รายละเอียดการทำงาน
พิจารณาอนุมัติคำขอยืม-คืน (Approve / Reject Requests) Admin ตรวจสอบคำขอยืมหรือเบิกที่ค้างอยู่ (Pending) แล้วกดปุ่มอนุมัติหรือปฏิเสธ เพื่อทำการหักหรือเพิ่มจำนวนสต็อกจริงในคลัง พร้อมส่งอีเมลแจ้งผลการพิจารณาโดยอัตโนมัติ
ตรวจสอบหลักฐานภาพถ่ายการคืน (Return Image Inspection) Admin กดดูรูปถ่ายสภาพครุภัณฑ์ที่ผู้ใช้ถ่ายตอนนำมาส่งคืน เพื่อตรวจจับความเสียหายก่อนที่จะกดยืนยันรับคืนอุปกรณ์เข้าสู่สต็อก
ระบบแดชบอร์ดรายงานเชิงวิเคราะห์ (Visual Statistics Charts) Admin แสดงผลแผนภูมิวงกลม (Pie Chart) เปรียบเทียบสัดส่วนระหว่างครุภัณฑ์คงทน (Durable) กับวัสดุสิ้นเปลือง (Consumable) และแผนภูมิแท่งยอดอัตราความนิยมในการกดยืมแต่ละเดือน
จัดการข้อมูลอุปกรณ์ในคลัง (Equipment Catalog Management) Admin แบบฟอร์มเพิ่มข้อมูลอุปกรณ์ใหม่ แก้ไขค่า หรือลบครุภัณฑ์ออกจากระบบคลังสะสม
แจ้งเตือนส่งจดหมายทวงคืนครุภัณฑ์ (Overdue Alert Mailing) Admin ตรวจคัดกรองใบยืมที่เกินเวลาส่งคืน แล้วสั่งการให้ส่งอีเมลแจ้งเตือนแจ้งภัยสีแดงเตือนคืนด่วน (Overdue warning email) ไปยังนักศึกษาโดยตรง
