บทที่ 4

ผลการดำเนินงาน

ผลการดำเนินงาน โครงงานระบบการยืมอุปกรณ์ห้องคอมพิวเตอร์ ของผู้ใช้บริการที่มีการเข้าใช้งานระบบ นำมาวิเคราะห์ข้อมูล ดังนี้

4.1 แบบสอบถามสำหรับผู้เชี่ยวชาญ แบ่งออกเป็น 2 ส่วนดังนี้
    ส่วนที่ 1 แบบสอบถามข้อมูลแสดงระดับความคิดเห็นของผู้เชี่ยวชาญที่มีต่อระบบการยืมอุปกรณ์ห้องคอมพิวเตอร์
    ส่วนที่ 2 แบบสอบถามข้อเสนอแนะ/ติชม
4.2 แบบสอบถามสำหรับผู้ใช้ทั่วไป แบ่งออกเป็น 3 ส่วนดังนี้
    ส่วนที่ 1 แบบสอบถามลักษณะทั่วไปของผู้ตอบแบบสอบถาม
    ส่วนที่ 2 แบบสอบถามข้อมูลแสดงระดับความคิดเห็นของผู้ใช้บริการทั่วไป
    ส่วนที่ 3 แบบสอบถามข้อเสนอแนะ/ติชมจากการรวบรวมข้อมูลของผู้ใช้ทั่วไป ที่ได้จากแบบสอบถาม ผู้จัดทำโครงงานได้นำข้อมูลดังกล่าวมาทำการวิเคราะห์เป็นผลของการทำโครงงาน ดังนั้นจะได้นำเสนอเป็นลำดับต่อไปนี้

4.1 แบบสอบถามสำหรับผู้เชี่ยวชาญ

4.1.1 แบบสอบถามข้อมูลแสดงระดับความคิดเห็นของผู้เชี่ยวชาญที่มีต่อระบบการยืมอุปกรณ์ห้องคอมพิวเตอร์

ตารางที่ 4-1 แสดงระดับความคิดเห็นของผู้เชี่ยวชาญ (จำนวน 3 ท่าน)
ประเด็นความคิดเห็น x̄ S.D. เกณฑ์ความคิดเห็น
1. ด้านความสามารถในการทำงานตามหน้าที่ของระบบ (Functional Requirement)
1.1 ระบบสามารถจัดการข้อมูลครุภัณฑ์และวัสดุได้อย่างถูกต้องและครบถ้วน 4.67 0.58 มากที่สุด
1.2 ระบบการยืม-คืนและการตัดสต็อกวัสดุมีความถูกต้องแม่นยำ 4.67 0.58 มากที่สุด
1.3 ระบบแจ้งเตือนทางอีเมลและการแจ้งเตือนค้างส่งทำงานได้ถูกต้อง 4.67 0.58 มากที่สุด
2. ด้านการออกแบบส่วนติดต่อผู้ใช้ (User Interface Design)
2.1 การจัดวางองค์ประกอบหน้าจอและลำดับขั้นตอนการทำงานมีความเหมาะสม 4.33 0.58 มาก
2.2 การเลือกใช้โทนสีและขนาดตัวอักษรมีความชัดเจน สบายตา อ่านง่าย 4.67 0.58 มากที่สุด
3. ด้านความปลอดภัยและความถูกต้องของข้อมูล (Security & Data Integrity)
3.1 มีระบบการตรวจสอบสิทธิ์และรักษาความปลอดภัยของข้อมูลที่รัดกุม 5.00 0.00 มากที่สุด
3.2 โครงสร้างฐานข้อมูลมีความสัมพันธ์เชิงสัมพันธ์ถูกต้องตามหลักการ 4.67 0.58 มากที่สุด
4. ด้านประสิทธิภาพการทำงานของระบบ (System Performance)
4.1 ความเร็วและความเสถียรในการประมวลผลและการค้นหาข้อมูล 4.67 0.58 มากที่สุด
รวมเฉลี่ย 4.67 0.43 มากที่สุด

ข้อความสรุปท้ายตาราง: จากตารางที่ 4-1 ผลการประเมินระดับความคิดเห็นของผู้เชี่ยวชาญที่มีต่อระบบการยืมอุปกรณ์ห้องคอมพิวเตอร์ พบว่า ในภาพรวมผู้เชี่ยวชาญมีความคิดเห็นอยู่ในระดับ "มากที่สุด" (x̄ = 4.67, S.D. = 0.43) โดยประเด็นที่ได้รับคะแนนประเมินสูงสุด ได้แก่ ด้านระบบการตรวจสอบสิทธิ์และรักษาความปลอดภัยของข้อมูลที่รัดกุม (x̄ = 5.00, S.D. = 0.00) รองลงมาได้แก่ ระบบสามารถจัดการข้อมูลครุภัณฑ์และวัสดุได้อย่างถูกต้องและครบถ้วน, ระบบการยืม-คืนและการตัดสต็อกวัสดุมีความถูกต้องแม่นยำ, ระบบแจ้งเตือนทางอีเมล และโครงสร้างฐานข้อมูล (x̄ = 4.67, S.D. = 0.58) ตามลำดับ แสดงให้เห็นว่าระบบมีมาตรฐาน ความปลอดภัย และความพร้อมในการนำไปใช้งานจริงได้อย่างมีประสิทธิภาพ

4.1.2 แบบสอบถามข้อเสนอแนะ/ติชม

จากการรวบรวมข้อเสนอแนะและความคิดเห็นเพิ่มเติมของผู้เชี่ยวชาญ สรุปได้ดังนี้
1. ควรมีการกำหนดรอบการสำรองข้อมูล (Automated Backup) ทั้งในรูปแบบฐานข้อมูลและประวัติการทำรายการอย่างสม่ำเสมอ เพื่อป้องกันความเสี่ยงกรณีเกิดเหตุขัดข้องของระบบคลาวด์
2. ควรเพิ่มช่องทางการแจ้งเตือนไปยังผู้ยืมผ่านแพลตฟอร์มอื่นเพิ่มเติม เช่น การแจ้งเตือนผ่านแอปพลิเคชัน LINE เพื่อเพิ่มความสะดวกรวดเร็วในการติดตามอุปกรณ์ที่ใกล้ถึงกำหนดส่งคืน
3. ควรจัดทำคู่มือการใช้งานระบบสำหรับผู้ดูแลระบบ (Admin Manual) อย่างละเอียด เพื่อให้เจ้าหน้าที่ท่านอื่นสามารถเข้ามาปฏิบัติงานแทนได้อย่างราบรื่น

โครงงานระบบการยืมอุปกรณ์ห้องคอมพิวเตอร์ หน้า 2

4.2 แบบสอบถามสำหรับผู้ใช้ทั่วไป

4.2.1 แบบสอบถามลักษณะทั่วไปของผู้ตอบแบบสอบถาม

การวิเคราะห์ข้อมูลลักษณะทั่วไปของผู้ตอบแบบสอบถาม ซึ่งเป็นนักเรียน/นักศึกษาสาขาวิชาคอมพิวเตอร์ จำนวน 50 คน จำแนกตามเพศ ระดับชั้นการศึกษา และความถี่ในการเข้าใช้บริการห้องปฏิบัติการคอมพิวเตอร์ ดังแสดงในตารางที่ 4-2 ถึง 4-4

ตารางที่ 4-2 แสดงจำนวนเพศของผู้ใช้ทั่วไปตอบแบบสอบถาม
เพศ จำนวน (คน) ร้อยละ
1. ชาย 28 56.00
2. หญิง 22 44.00
รวม 50 100.00

ข้อความสรุปท้ายตาราง: จากตารางที่ 4-2 พบว่า ผู้ตอบแบบสอบถามส่วนใหญ่เป็นเพศชาย จำนวน 28 คน คิดเป็นร้อยละ 56.00 และเพศหญิง จำนวน 22 คน คิดเป็นร้อยละ 44.00 ตามลำดับ

ตารางที่ 4-3 แสดงจำนวนระดับชั้นการศึกษาของผู้ใช้ทั่วไปตอบแบบสอบถาม

4.2.2 แบบสอบถามข้อมูลแสดงระดับความคิดเห็นของผู้ใช้บริการทั่วไป

ตารางที่ 4-5 แสดงระดับความคิดเห็นของผู้ใช้บริการทั่วไป (จำนวน 50 คน)
ประเด็นความคิดเห็น x̄ S.D. เกณฑ์ความคิดเห็น
1. ด้านความตรงตามความต้องการของระบบ (Functional Requirements)
1.1 ความสะดวกในการค้นหาและคัดกรองข้อมูลครุภัณฑ์ตามอาคารและห้องจัดเก็บ 4.52 0.61 มากที่สุด
1.2 ความสะดวกรวดเร็วในการยื่นคำขอยืมครุภัณฑ์และการขอเบิกวัสดุสิ้นเปลือง 4.56 0.54 มากที่สุด
1.3 ความสะดวกในการแนบรูปถ่ายหลักฐานสภาพอุปกรณ์ขณะส่งคืน 4.52 0.58 มากที่สุด
1.4 ความสามารถในการตรวจสอบประวัติและติดตามสถานะคำขอยืม-คืนของตนเอง 4.48 0.54 มาก
2. ด้านความง่ายต่อการใช้งาน (Usability & User-friendliness)
2.1 ขั้นตอนการเข้าสู่ระบบและสมัครสมาชิกมีความสะดวกรวดเร็ว 4.52 0.61 มากที่สุด
2.2 รูปแบบเมนูและฟังก์ชันการใช้งานเข้าใจง่าย ไม่ซับซ้อน 4.60 0.53 มากที่สุด
2.3 การแจ้งเตือนสถานะผ่านทางอีเมลมีความชัดเจนและเป็นประโยชน์ 4.52 0.58 มากที่สุด
3. ด้านการออกแบบส่วนติดต่อผู้ใช้ (User Interface Design)
3.1 ความสวยงาม ทันสมัย และความสบายตาของหน้าเว็บ 4.46 0.61 มาก
3.2 ความชัดเจนของรูปภาพ รหัสครุภัณฑ์ และสถานะคงเหลือของอุปกรณ์ 4.58 0.57 มากที่สุด
3.3 การรองรับการแสดงผลทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน (Responsive) 4.58 0.64 มากที่สุด
4. ด้านประสิทธิภาพและความเร็วของระบบ (System Performance)
4.1 ความรวดเร็วในการโหลดหน้าเว็บและการค้นหาอุปกรณ์ 4.62 0.57 มากที่สุด
4.2 ความเสถียรในการประมวลผลและการทำงานโดยรวมของระบบ 4.58 0.57 มากที่สุด
รวมเฉลี่ย 4.54 0.58 มากที่สุด

ข้อความสรุปท้ายตาราง: จากตารางที่ 4-5 ผลการประเมินระดับความคิดเห็นของผู้ใช้บริการทั่วไป (นักเรียน/นักศึกษาสาขาวิชาคอมพิวเตอร์ จำนวน 50 คน) ที่มีต่อระบบการยืมอุปกรณ์ห้องคอมพิวเตอร์ พบว่า ในภาพรวมผู้ใช้บริการมีความพึงพอใจอยู่ในระดับ "มากที่สุด" (x̄ = 4.54, S.D. = 0.58) เมื่อพิจารณาเป็นรายข้อ พบว่า ประเด็นที่ผู้ใช้บริการมีความคิดเห็นสูงที่สุด คือ ความรวดเร็วในการโหลดหน้าเว็บและการค้นหาอุปกรณ์ (x̄ = 4.62, S.D. = 0.57) รองลงมาได้แก่ รูปแบบเมนูและฟังก์ชันการใช้งานเข้าใจง่าย ไม่ซับซ้อน (x̄ = 4.60, S.D. = 0.53), ความชัดเจนของรูปภาพ รหัสครุภัณฑ์ และสถานะคงเหลือ (x̄ = 4.58, S.D. = 0.57), การรองรับการแสดงผลทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน (x̄ = 4.58, S.D. = 0.64) และความสะดวกรวดเร็วในการยื่นคำขอยืมครุภัณฑ์ (x̄ = 4.56, S.D. = 0.54) ตามลำดับ แสดงว่าระบบสามารถตอบโจทย์ความต้องการของผู้เรียนได้อย่างมีประสิทธิภาพสูง

4.2.3 แบบสอบถามข้อเสนอแนะ/ติชมจากการรวบรวมข้อมูลของผู้ใช้ทั่วไป

จากการรวบรวมข้อเสนอแนะและข้อคิดเห็นเพิ่มเติมของผู้ใช้บริการทั่วไป (นักเรียน/นักศึกษา) สรุปได้ดังนี้
1. ระบบใช้งานง่าย สะดวกในการตรวจสอบว่าอุปกรณ์ชิ้นใดว่างให้ยืมจริงโดยไม่ต้องเดินไปถามเจ้าหน้าที่ที่ห้องปฏิบัติการ
2. อยากให้มีระบบแจ้งเตือนเตือนความจำล่วงหน้า 1 วัน ก่อนถึงกำหนดส่งคืนครุภัณฑ์
3. หน้าตาเว็บไซต์มีความสวยงาม ทันสมัย และสามารถเปิดใช้งานบนโทรศัพท์มือถือได้อย่างสะดวก รวดเร็ว
