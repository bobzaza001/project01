1. ภาษาโปรแกรม เทคโนโลยี และสถาปัตยกรรมระบบ (Tech Stack)

โครงงานระบบการยืมอุปกรณ์ห้องคอมพิวเตอร์ได้รับการพัฒนาขึ้นโดยใช้สถาปัตยกรรมเว็บแอปพลิเคชันแบบ Modular Architecture แยกโครงสร้างการทำงานออกเป็นส่วนต่างๆ อย่างเป็นระเบียบ โดยมีรายละเอียดภาษาโปรแกรมและเครื่องมือที่ใช้ ดังนี้

ส่วนประกอบ ภาษา / เทคโนโลยีที่ใช้ หน้าที่และการทำงานในระบบ
Back-End Language Python 3.11+ ประมวลผลตรรกะทางธุรกิจ (Business Logic), คำนวณวันยืม-คืน, ระบบตัดสต็อกอัตโนมัติ และการตรวจสอบความปลอดภัย
Web Framework Flask Framework โครงสร้างแบบ Modular Blueprints (auth, admin, user) จัดการ Routing และ Middleware
Database Engine PostgreSQL (Cloud) / SQLite (Dev) ฐานข้อมูลเชิงสัมพันธ์ Relational Database รองรับการจัดเก็บข้อมูลแบบ ACID และคีย์ Foreign Keys
Database ORM SQLAlchemy (Flask-SQLAlchemy) จัดการโมเดลฐานข้อมูลเชิงวัตถุ ความสัมพันธ์แบบ 1:M และ M:N
Authentication & Security Flask-Login & Werkzeug Security จัดการ Session ผู้ใช้งาน และการเข้ารหัสผ่านแบบ Scrypt Password Hashing
Notification System Flask-Mail (SMTP TLS via Gmail) ส่งอีเมลแจ้งเตือนอัตโนมัติเมื่ออนุมัติคำขอ, ปฏิเสธคำขอ และแจ้งเตือนเมื่อใกล้ถึงกำหนดส่งคืน
Image Processing Pillow (PIL) ปรับขนาดและบีบอัดรูปถ่ายสภาพอุปกรณ์ และจัดเก็บเป็น Base64 Data URL
Reporting Engine OpenPyXL & ReportLab ส่งออกรายงานสรุปประวัติเป็นไฟล์ Excel (.xlsx) และสร้างเอกสารทางการ PDF ขนาด A4
Front-End Core HTML5 & Jinja2 Template โครงสร้างหน้าเว็บและเทมเพลตฝั่งเซิร์ฟเวอร์แบบ Server-Side Rendering
Styling & UI Modern CSS3 (Glassmorphism) ออกแบบหน้าเว็บแบบ Responsive รองรับทั้งคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน (Dark/Light Mode)
Client Scripting Vanilla JavaScript (ES6+) ระบบค้นหาแบบเรียลไทม์ (Debounced Filter), ระบบแท็บ, Modal Popup และ PWA Service Worker
QR Code & Scanner HTML5-QRCode Scanner เปิดกล้องสมาร์ตโฟนสแกน QR Code เข้าสู่ระบบและตรวจสอบข้อมูลอุปกรณ์
Cloud Deployment Vercel Cloud & Neon PostgreSQL ระบบคลาวด์เซิร์ฟเวอร์เลส รองรับการทำงานออนไลน์ตลอด 24 ชั่วโมง เชื่อมต่อ GitHub CI/CD อัตโนมัติ

3. รายละเอียดฟังก์ชันการทำงานของระบบ (System Features & Modules)

3.1 โมดูลระบบยืนยันตัวตนและกู้คืนบัญชี (Auth & Account Recovery)

  • การสมัครสมาชิกด้วยรหัสนักศึกษา: นักศึกษากรอกรหัสนักศึกษา 11 หลัก และอีเมลสถาบัน โดยระบบจะนำรหัสนักศึกษาไปเป็น Username ในการเข้าสู่ระบบโดยอัตโนมัติ
  • การล็อกอินอัจฉริยะ: รองรับการพิมพ์รหัสนักศึกษา 11 หลัก, ชื่อผู้ใช้, ชื่อ-นามสกุลจริง หรืออีเมลสถาบัน ในช่องเดียว
  • ศูนย์กู้คืนบัญชีผู้ใช้งาน (Account Recovery Center):
    • แท็บค้นหาชื่อผู้ใช้ (Find Username): กรอกอีเมลสถาบันเพื่อค้นหา Username และรหัสนักศึกษา
    • แท็บรีเซ็ตรหัสผ่านใหม่ด้วย OTP (OTP Reset): ยืนยันรหัส OTP 6 หลัก แล้วตั้งรหัสผ่านใหม่ได้ทันทีผ่านหน้าเว็บ

3.2 โมดูลคลังอุปกรณ์และการค้นหา (Catalog & Smart Filters)

  • ระบบตัวกรอง 4 มิติ: กรองแยกตามประเภท (ครุภัณฑ์/วัสดุสิ้นเปลือง), กรองตามสถานที่ (อาคาร/ชั้น/ห้อง), กรองตามหมวดหมู่ และกรองตามสิทธิ์พกพา
  • ระบบค้นหาเรียลไทม์ (Debounced Search): ค้นหาตามชื่ออุปกรณ์ รหัสครุภัณฑ์ หรือยี่ห้อ ได้ทันทีขณะพิมพ์แบบลื่นไหล

3.3 โมดูลขั้นตอนการยืม-คืน และการเบิกวัสดุ (Borrow-Return Workflow)

  • การขอยืมครุภัณฑ์: ระบุวันเวลารับของ และจำนวนวันยืม 1-30 วัน พร้อมระบบป้องกันของหมดสต็อกและป้องกันคำขอซ้ำซ้อน
  • การขอเบิกวัสดุสิ้นเปลือง: ระบุจำนวนที่ต้องการเบิกใช้งานเพื่อส่งเรื่องตัดสต็อกโดยไม่ต้องนำมาคืน
  • การส่งคืนพร้อมแนบรูปถ่ายหลักฐาน: ผู้ยืมต้องอัปโหลดรูปถ่ายสภาพอุปกรณ์ตอนส่งคืน เพื่อให้แอดมินตรวจสภาพของก่อนกดยืนยันรับคืนเข้าคลัง

3.4 โมดูลการบริหารจัดการของผู้ดูแลระบบ (Admin Management)

  • Admin Dashboard: รวมสถิติสต็อกคงคลัง, รายการรออนุมัติ, รายการตรวจรับคืน และรายการแจ้งซ่อม
  • ศูนย์รวมประวัติการยืม-คืน: รวมประวัติทุกรายการพร้อมตัวกรองสถานะและช่องค้นหาอัจฉริยะ
  • ระบบตรวจสอบประวัติการแก้ไขข้อมูล (Audit Logs): บันทึกประวัติกิจกรรมของแอดมินทุกครั้งเมื่อมีการเพิ่ม/แก้/ลบ เพื่อความโปร่งใส
  • ระบบจัดการผังสถานที่: เพิ่ม/แก้ไข/ลบ รายชื่ออาคารเรียน ชั้นเรียน และห้องปฏิบัติการ
  • ระบบรายงานทางการ: ดาวน์โหลดไฟล์ Excel (.xlsx) และเปิดพิมพ์หน้ารายงานทางการ PDF (A4) พร้อมช่องลงนาม
