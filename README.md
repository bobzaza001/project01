# 🔬 LAB Equipment Management System

ระบบจัดการครุภัณฑ์ห้องปฏิบัติการแบบออนไลน์ (LAB Equipment Management System) พัฒนาด้วย **Flask (Python)** รองรับทั้งการทำงานร่วมกับฐานข้อมูล **Supabase (PostgreSQL)** และฐานข้อมูลภายในเครื่อง **SQLite** 

มีระบบแจ้งเตือนทางอีเมลเมื่อทำรายการ อนุมัติ/ปฏิเสธ หรือเตือนความจำเมื่อใกล้ครบกำหนดส่งคืนอุปกรณ์

---

## 🚀 ฟีเจอร์เด่น
* **แดชบอร์ด:** สรุปสถิติต่างๆ สำหรับผู้ใช้งานทั่วไปและผู้ดูแลระบบ (Admin)
* **คลังอุปกรณ์:** ค้นหา กรองประเภท/หมวดหมู่/ที่ตั้ง และส่งคำขอยืมครุภัณฑ์หรือเบิกวัสดุสิ้นเปลือง
* **แจ้งเตือนอีเมลอัตโนมัติ:** แจ้งผลการอนุมัติ/ปฏิเสธ และส่งอีเมลเตือนล่วงหน้า 1 วันก่อนครบกำหนดคืนเวลา 08:00 น.
* **ระบบจัดการสิทธิ์การเข้าถึง:** แดชบอร์ดแอดมินแยกกับแดชบอร์ดผู้ใช้ธรรมดาอย่างชัดเจน
* **รองรับ 2 โหมดการแสดงผล:** โหมดสว่าง (Light Mode) และโหมดมืด (Dark Mode) ดีไซน์พรีเมียม สบายตา

## 🛠️ วิธีการติดตั้งและรันใช้งาน

### 1. โคลนโครงการ (Clone Project)
```bash
git clone <url-of-your-repository>
cd <project-directory>
```

### 2. สร้าง Virtual Environment และติดตั้ง Dependencies
```bash
python -m venv venv
# เปิดใช้งาน venv (บน Windows)
venv\Scripts\activate
# เปิดใช้งาน venv (บน macOS / Linux)
source venv/bin/activate

# ติดตั้งแพ็กเกจที่จำเป็น
pip install -r requirements.txt
```

### 3. ตั้งค่าสภาพแวดล้อม (Environment Setup)
คัดลอกไฟล์ `.env.example` ไปเป็น `.env` แล้วระบุข้อมูลการเชื่อมต่อจริงของคุณ:
```bash
cp .env.example .env
```
เปิดไฟล์ `.env` และกำหนดค่าต่างๆ:
* **DATABASE_URL:** ลิงก์ฐานข้อมูล PostgreSQL ของ Supabase (หากต้องการรัน SQLite ให้คอมเมนต์บรรทัดนี้ด้วย `#`)
* **SECRET_KEY:** คีย์ความปลอดภัยสำหรับ Session
* **MAIL_USERNAME & MAIL_PASSWORD:** อีเมลส่งแจ้งเตือนและรหัสผ่านสำหรับแอป (Google App Password)

### 4. อัปเดตโครงสร้างฐานข้อมูล (Database Schema)
รันสคริปต์เพื่อสร้างตารางและคอลัมน์ที่จำเป็นทั้งหมด:
```bash
python -m scripts.alter_table
```

*(ทางเลือก)* หากต้องการสร้างข้อมูลจำลองผู้ใช้ แอดมิน และอุปกรณ์สำหรับทดสอบ ให้รัน:
```bash
python -m scripts.init_db
```

### 5. เริ่มรันเซิร์ฟเวอร์ (Start App)
```bash
python app.py
```
เปิดเว็บเบราว์เซอร์ไปที่: **[http://127.0.0.1:5000](http://127.0.0.1:5000)**

## 📦 โครงสร้างโฟลเดอร์หลัก
* `blueprints/`: เก็บเส้นทางเชื่อมโยงของระบบแยกเป็นหมวดหมู่ (auth, admin, user)
* `static/`: ไฟล์สไตล์ CSS, สคริปต์ JS และโฟลเดอร์อัปโหลดรูปภาพ (`uploads/`)
* `templates/`: หน้าเอกสาร HTML (Jinja2 Templates)
* `models.py`: โครงสร้างตารางข้อมูลในระบบ
* `notifications.py`: โมดูลสำหรับจัดการระบบส่งอีเมลแจ้งเตือน
* `app.py`: จุดเริ่มทำงานหลักของระบบและตั้งค่า Scheduler รายวัน
